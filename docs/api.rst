API Reference
=============

This page documents the public Python surface that feeds the examples gallery.
The best way to read it is:

- start with ``mplvega.pyplot`` for plotting calls
- use ``savefig()`` suffixes to choose JSON, HTML, or rendered outputs
- look at the examples gallery for concrete visual behavior

``mplvega`` intentionally documents the supported pyplot-shaped subset rather
than trying to mirror every matplotlib keyword equally well.
